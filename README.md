# Python-Monthly-data-analysis
This project demonstrates a simple monthly sales analysis using Python for data visualization.

## Project Overview

The project creates a dataset containing monthly sales figures, analyzes the data using Pandas, identifies months with high sales, and visualizes monthly sales performance using a line chart.

## Dataset

The dataset contains sales information for five months:

| Month | Sales |
|-------|-------|
| Jan   | 10    |
| Feb   | 15    |
| Mar   | 25    |
| Apr   | 20    |
| May   | 30    |

## Analysis

The project uses Python to:

- Create a monthly sales dataset
- Store the data in a Pandas DataFrame
- Identify months where sales are greater than 15
- Display the high-sales months
- Visualize monthly sales performance using a line chart

## Key Features

- Data creation using Python
- Data manipulation with Pandas
- Conditional analysis using `if` statements
- Iteration through DataFrame rows
- Monthly sales visualization
- Line chart with data markers

## Tools and Libraries

- Python
- Pandas
- Matplotlib

## Visualization

The project generates a line chart titled:

**Monthly Sales Performance**

The chart shows how sales change from January to May.

## Project Purpose

This project demonstrates basic Python skills in data analysis, conditional logic, DataFrame manipulation, and data visualization.
